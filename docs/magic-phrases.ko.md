# 마법의 한마디 카드

외울 필요 없어요. 까먹으면 "내 기억 목록 줘"라고 하면 이 카드가 다시 나와요.

| 이렇게 말하면 | 일어나는 일 |
|---|---|
| "예제 해 볼래" (또는 `/example`) | 점심 메뉴 고르기 / 추억의 게임 박물관 중 하나를 골라, 프롬프트 → 앱 → 배포 → 공유까지 따라 해요 |
| "새 프로젝트 시작하자" | 몇 가지 질문에 답하면 프로젝트를 세팅해 줘요 |
| "노래 랭킹 만들래" / "점심 메뉴 추천 사이트 만들래" | 예제 레시피로 바로 시작해요 |
| "실행해줘" | 내 컴퓨터에서 켜 보고, 같은 와이파이 폰으로도 볼 수 있어요 |
| "예쁘게 해줘" / "이 사이트처럼 해줘" | 분위기를 고르고 예쁜 부품으로 꾸며요 |
| "로그인 넣어줘" | 로그인 방식(없음, 이메일, 구글, 우리끼리만) 중에 골라요 |
| "5살처럼 설명해줘" → "한 단계 더" | 모르는 말을 아주 쉽게, 그다음 조금씩 깊게 |
| "이거 기억해 둬" / "내 기억 목록 줘" / "퀴즈 내 줘" | 나만의 기억 목록과 복습 |
| "저장해 둬" / "아까 잘 되던 때로 되돌려줘" | 저장 포인트와 되돌리기 |
| 일하는 중에 또 부탁하기 | 할 일 목록에 차례대로 쌓아 두고, 지금 하던 걸 끝낸 뒤 하나씩 해요. 한 창(세션)에서 다 해요 |
| "뭐 남았어?" / "이거 먼저 해줘" | 할 일 목록을 보여 주거나 순서를 바꿔요 |
| "마무리해" / "머지해" | 끝난 작업을 메인에 합치고(원격 저장소가 있으면 푸시까지), 창을 닫을지 먼저 물어봐요 |
| 같은 폴더에서 창을 하나 더 열면 | 서로 덮어쓸 수 있다고 경고해요. 그래도 하겠다고 하면 작업용 복사본(워크트리)에서 하고, 끝나면 합친 뒤 닫을지 물어봐요 |
| "안전 점검해줘" | 키 노출, 데이터 규칙, 비용 한도, 테스트를 확인해요 |
| "파이어베이스 연결해줘" | 계정 만들기와 로그인 한 번만 직접 하면, 나머지 설정은 AI가 명령어로 다 해요 |
| "배포해줘" | 점검 후 인터넷에 올려요 (무료 주소 `이름.web.app`) |
| "QR 코드 만들어줘" / "공유 카드 만들어줘" | 배포한 주소를 링크, QR 코드, 공유 이미지, 카톡 미리보기로 만들어 줘요 |
| "API 키 넣어줘" | 한 달 한도부터 정하고, 키는 안전한 곳에만 둬요 |

## 잊지 말 것 세 가지

1. **까먹어도 괜찮아요.** 계속 물어보면 결국 기억돼요. AI는 같은 질문을 열 번 해도 처음처럼 답해 줘요.
2. **API 키는 신용카드예요.** 한도부터 걸고, 코드나 GitHub에는 절대 넣지 않아요.
3. **망쳐도 괜찮아요.** 저장 포인트가 있으면 언제든 되돌릴 수 있어요.
