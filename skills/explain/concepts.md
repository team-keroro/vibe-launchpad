# Core concepts with analogies

Each entry: 5살 analogy → 중학생 idea → common beginner trap. Adapt freely; never read these verbatim twice in a row.

## Local vs website (localhost)

- 5살: 내 방 안에 차린 가게. 나는 들어갈 수 있지만 밖에 있는 친구는 못 들어와요.
- 중학생: `http://localhost:5173` 은 "이 컴퓨터 자신"을 뜻하는 주소. 친구 폰에서 열면 친구 폰 자기 자신을 찾아서 실패한다. 같은 와이파이라면 내 컴퓨터의 내부 주소(예: `192.168.0.12:5173`)로는 들어올 수 있다.
- Trap: 컴퓨터를 끄거나 터미널을 닫으면 사이트도 꺼진다. 세상에 열려면 "배포"해야 한다.

## Port

- 5살: 큰 건물(컴퓨터) 안의 호수. 5173호에 내 사이트가 산다.
- Trap: "포트가 이미 사용 중" = 그 방에 이미 다른 프로그램이 있다. 다른 호수를 쓰거나 이전 것을 끈다.

## Hosting / server

- 5살: 24시간 문을 여는 상가를 빌리는 것. 내 컴퓨터를 꺼도 가게는 열려 있다.
- 중학생: 다른 회사의 컴퓨터(Firebase 등)에 내 사이트 파일을 올려 두면 그 컴퓨터가 대신 손님을 받는다.

## Domain / DNS

- 5살: 가게 간판과 주소. 사람들은 숫자 주소 대신 이름으로 찾아온다.
- 중학생: DNS는 인터넷 주소록. `mysongs.com` → 실제 컴퓨터 숫자 주소. 도메인을 사면 이 주소록에 내 이름을 올릴 권리를 1년씩 빌리는 것.
- Trap: 연결 후 바로 안 열리는 건 정상(주소록이 퍼지는 데 몇 분~몇 시간).

## Website vs web app vs native app vs PWA

- 웹사이트: 보여 주기만 하는 곳 (가게 전단지)
- 웹앱: 브라우저에서 로그인하고 데이터를 다루는 프로그램 (가게 안 키오스크)
- 네이티브 앱: 앱스토어에서 설치. 심사와 등록비(애플 연 $99, 구글 1회 $25)가 있다.
- PWA: 웹앱을 폰 홈 화면에 앱처럼 설치하는 방법. 심사 없음, 무료.
- Takeaway: "앱 만들고 싶다"의 대부분은 웹앱(+PWA)으로 시작하면 오늘 바로, 무료로 된다.

## Git vs GitHub

- 5살: Git은 게임 세이브. GitHub는 세이브 파일을 인터넷 금고에 복사해 두는 것.
- 중학생: Git은 내 컴퓨터 안에서 "저장 포인트"를 만들고 언제든 그때로 되돌린다. 인터넷도 계정도 필요 없다. GitHub는 백업과 협업이 필요할 때 붙인다.
- Takeaway: 컴퓨터 분실은 드물다. 처음엔 Git만으로 충분. 진짜 자주 쓰는 건 백업보다 "되돌리기".
- Trap: GitHub에, 특히 공개 저장소에 올릴 때 키가 가장 많이 샌다.

## Frontend / backend

- 5살: 프론트엔드는 손님이 보는 홀, 백엔드는 손님이 못 들어가는 주방.
- Trap: 프론트엔드 코드는 손님(누구나) 다 볼 수 있다. 비밀은 여기 두면 안 된다.

## Database

- 5살: 가게의 장부. 손님이 남긴 투표, 글이 여기에 적힌다.
- 중학생: Firestore 는 인터넷에 있는 장부. "누가 어느 칸을 읽고 쓸 수 있는지" 규칙(보안 규칙)을 꼭 정해야 한다.
- Trap: 화면에서 버튼을 숨기는 건 보안이 아니다. 장부 규칙에서 막아야 진짜 막힌 것.

## API key

- 5살: 신용카드. 누가 주워 쓰면 내 돈이 나간다.
- 중학생: 다른 회사 서비스(AI 등)를 쓸 때 "나예요"를 증명하는 비밀 문자열. 쓴 만큼 내 카드로 청구된다.
- Trap: 프론트엔드 코드나 GitHub에 들어가면 누구나 복사할 수 있다. 그래서 (1) 한도부터 걸고 (2) 비밀 키는 서버에만 둔다.
- Note: Firebase 웹 설정의 `apiKey` 는 공개돼도 되는 "가게 이름표" 같은 값. AI 회사 키와 다르다.

## Environment variables (.env)

- 5살: 금고 안 쪽지. 코드에 직접 적지 않고 금고에서 꺼내 쓴다.
- Trap: `.env` 파일은 절대 Git/GitHub에 올리지 않는다(.gitignore).
- Trap: Vite 에서 `VITE_` 로 시작하는 값은 브라우저 코드에 그대로 들어간다 = 공개된다.

## Build / deploy

- 5살: 빌드는 요리를 포장하는 것, 배포는 포장한 걸 상가에 진열하는 것.

## HTTPS

- 5살: 편지를 봉투에 넣어 보내는 것. 중간에서 못 훔쳐본다. Firebase 는 자동으로, 무료로 해 준다.

## Component vs logic (hooks)

- 5살: 식당의 홀(화면)과 주방(레시피). 인테리어를 바꿔도 레시피는 그대로라 맛이 안 변한다.
- Takeaway: 이렇게 나누면 AI가 디자인을 고치다가 기능을 망가뜨리는 일이 줄어든다.

## Tests

- 5살: 레시피대로 하면 그 맛이 나는지 자동으로 맛보는 것. 뭔가 바꿀 때마다 1초 만에 다시 맛본다.
