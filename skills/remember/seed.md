# 내가 기억할 것

## 마음가짐
- **까먹어도 괜찮다** — 배우고 까먹고를 반복하면 결국 기억된다. AI는 같은 질문을 열 번 해도 처음처럼 답해 준다. 포기하지 말고 물어보기.

## 마법의 한마디
- **"새 프로젝트 시작하자"** — 질문 몇 개에 답하면 프로젝트를 세팅해 준다.
- **"5살처럼 설명해줘" → "한 단계 더"** — 설명 사다리. 이해되면 한 단계씩 올린다.
- **"이거 기억해 둬" / "내 기억 목록 줘" / "퀴즈 내 줘"** — 이 목록.
- **"아까 잘 되던 때로 되돌려줘"** — Git 저장 포인트로 되돌리기.
- **"안전 점검해줘"** — 키 노출, 데이터 규칙, 비용 한도, 테스트를 확인.
- **"배포해줘"** — 점검 후 인터넷에 올리기.

## 보안·비용
- **API 키는 신용카드** — 새 나가면 남이 내 돈을 쓴다. 키를 만들기 전에 월 한도부터 건다.
- **알림과 한도는 다르다** — 예산 "알림"은 메일만 보내고 멈추지 않는다. "한도"가 있는 곳은 한도를 건다.
- **AI는 만들 때 쓰고 앱에는 넣지 않는다** — 결과를 미리 만들어 둘 수 있으면 키가 필요 없다.
- **비밀 키는 브라우저 코드에 절대 넣지 않는다** — 꼭 필요하면 서버를 거친다.
- **.env 는 Git/GitHub에 올리지 않는다.**
- **새 나갔으면 바로 폐기하고 새로 발급** — 지우는 것만으로는 안 된다(Git 기록에 남는다).

## 개념
- **localhost** — 내 방 안의 가게. 친구 폰에서는 안 열린다. 세상에 열려면 배포.
- **Git vs GitHub** — Git은 내 컴퓨터 안의 게임 세이브, GitHub는 인터넷 금고. 처음엔 Git만으로 충분.
- **숨기기 vs 막기** — 화면에서 버튼을 숨기는 건 보안이 아니다. 데이터 규칙에서 막아야 진짜 막힌 것.
